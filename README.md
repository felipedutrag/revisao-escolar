## 📌 Overview

**Astro Tutor** is an interactive study platform and pedagogical revision assistant featuring a space exploration visual theme.

The application allows students and educators to paste study materials or lecture notes, generate automated quiz questions, receive step-by-step explanatory summaries, and export revision sheets as formatted PDFs.

---

## ✨ Key Features

- 🌌 **Cosmic Interface:** Clean interstellar UI with glowing indicators and intuitive content blocks.
- 📝 **Automated Study Sheet Compilation:** Generates structured bullet-point summaries and flash questions from raw text.
- 🖨️ **Client-Side PDF Generation:** Instant export to clean, printable PDF worksheets using `jsPDF`.
- 🎙️ **Audio Transcription & Correction:** Fixes transcription typos and formats spoken lecture transcripts into study materials.
